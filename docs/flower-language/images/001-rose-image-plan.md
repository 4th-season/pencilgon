# 001 장미 이미지 제작계획

연결 글 제목: **[꽃과 꽃말] ㆍ장미ㆍ색깔마다 달라지는 사랑의 언어**

장미 편은 시리즈 전체의 이미지 기준을 결정하는 기준 글이다. 아름다운 분위기보다 먼저 **장미라는 대상이 정확히 보이는가**를 검수한다.

---

## 공통 시각 기준

- 기본 분위기: 자연광 실사형, 과도한 보케와 필터 금지
- 꽃잎: 장미 특유의 겹꽃 구조와 나선형 중심이 분명해야 함
- 잎: 깃꼴겹잎과 톱니 모양이 자연스럽게 보이도록 함
- 줄기: 모든 장미가 똑같이 굵은 가시를 지닌 것처럼 과장하지 않음
- 색상: 빨강·분홍·노랑·흰색의 차이를 인위적인 형광색으로 만들지 않음
- 텍스트: 썸네일 외에는 이미지 안 문장 최소화
- 인물: 선물 장면에서는 얼굴보다 손·꽃다발·관계의 거리 중심
- 생성형 이미지 검수: 꽃잎의 비정상적인 반복, 잎과 꽃의 연결 오류, 가시 위치, 꽃송이 융합 여부 확인

---

## 이미지 0｜썸네일

- 비율: 1:1
- 역할: 목록과 검색 화면에서 장미 편임을 즉시 알림
- 구성: 중앙에 진홍색 장미 한 송이, 뒤쪽에 흐릿한 분홍·흰색·노란 장미
- 텍스트: `장미` / `색깔마다 달라지는 사랑의 언어`
- 배경: 짙은 녹색과 크림색의 절제된 조합
- 금지: 하트 아이콘 과다 사용, 웨딩 광고 같은 장식, 꽃잎이 장미가 아닌 작약처럼 보이는 표현

### 생성 지시문

자연광에서 촬영한 사실적인 장미 정물 사진. 중앙에 완전히 피기 직전의 진홍색 하이브리드 티 장미 한 송이, 뒤에는 분홍색·흰색·노란색 장미가 부드럽게 흐려져 있으나 각 꽃의 색은 구분된다. 장미 특유의 나선형 꽃잎 중심과 톱니가 있는 짙은 녹색 잎이 정확하게 보인다. 고급 식물도감과 정갈한 한국 잡지 표지의 중간 분위기. 1:1 구도, 과한 보케·반짝임·하트·리본 없음, 텍스트를 넣을 상단 여백 확보.

---

## 이미지 1｜대표 대상 이미지

- 비율: 16:9
- 삽입 위치: 도입부 뒤
- 역할: 장미의 전체적인 형태를 보여주는 첫 실사 이미지
- 구성: 정원에서 피어 있는 붉은 장미 3~5송이와 잎·줄기
- 확인 요소: 꽃 중심, 겹꽃잎, 잎의 톱니, 줄기의 자연스러운 가시
- 설명 연결: 꽃집의 절화만이 아니라 장미가 본래 목본성 식물이라는 점

### 생성 지시문

초여름 아침의 장미 정원에서 촬영한 고해상도 식물 사진. 붉은 장미 3~5송이가 서로 다른 개화 단계로 피어 있고, 녹색 줄기와 깃꼴겹잎, 잎 가장자리의 작은 톱니가 분명하다. 가시는 줄기 일부에만 자연스럽게 보인다. 배경은 실제 정원이지만 대상 식별을 방해하지 않을 정도로만 흐리다. 16:9, 식물도감 수준의 사실성, 꽃잎 융합과 비현실적 잎 배열 없음.

---

## 이미지 2｜장미 구조 상세

- 비율: 1:1
- 삽입 위치: ‘장미를 한눈에 보면’
- 역할: 꽃·잎·줄기·열매를 한 장에서 설명
- 구성: 네 칸 비교 또는 한 식물의 부분 확대
  1. 나선형으로 겹친 꽃잎
  2. 톱니가 있는 겹잎
  3. 가시처럼 보이는 피침 구조
  4. 붉은 장미 열매(rose hip)
- 텍스트: `꽃 / 잎 / 줄기 / 열매`만 사용

### 제작 방식

생성형 단일 사진보다 **실사 사진 4장을 조합한 설명형 카드**를 우선한다. 이미지 생성이 필요하면 각 요소를 따로 만든 후 Canva에서 조합한다.

## 이미지 3｜색깔별 장미 비교

- 비율: 16:9
- 삽입 위치: 색깔별 꽃말 섹션
- 역할: 빨강·분홍·노랑·흰색 장미를 같은 조건에서 비교
- 구성: 네 송이를 같은 크기·같은 각도·같은 배경으로 배열
- 하단 핵심어:
  - 빨강: 사랑·열정
  - 분홍: 다정함·감사
  - 노랑: 우정·기쁨
  - 흰색: 순수·존중
- 주의 문구: `꽃말은 시대와 문화에 따라 달라질 수 있습니다.`

### 생성 지시문

식물도감식 비교 촬영. 붉은 장미, 연분홍 장미, 선명하지만 자연스러운 노란 장미, 순백색 장미 네 송이를 같은 개화 단계와 같은 측면 각도로 나란히 배치한다. 중성적인 밝은 크림색 배경, 각 꽃 아래 설명을 넣을 여백, 꽃의 크기와 줄기 길이가 균일하다. 16:9, 상품 광고가 아니라 교육용 비교 이미지, 형광색·리본·꽃다발 포장 없음.

---

## 이미지 4｜장미 상징의 흐름

- 비율: 16:9
- 삽입 위치: 신화·역사·문화 섹션
- 역할: 장미가 사랑만이 아니라 여러 상징을 지녔음을 보여줌
- 구성: 가로 흐름도
  1. 고대 그리스·로마 — 사랑과 아름다움
  2. `sub rosa` — 비밀과 침묵
  3. 중세 종교미술 — 순결과 신성한 사랑
  4. 장미전쟁 — 가문과 권력
  5. 빅토리아 시대 — 꽃으로 보내는 메시지
- 시각 스타일: 고서 삽화와 현대 인포그래픽의 절제된 결합

### 제작 주의

특정 역사 인물을 사실처럼 재현하지 않는다. 꽃·문장·문장(紋章)·봉인된 편지 같은 사물 중심으로 상징을 표현한다.

---

## 이미지 5｜선물 상황별 장미

- 비율: 16:9
- 삽입 위치: 선물 가이드
- 역할: 관계와 상황에 맞는 형태를 직관적으로 제시
- 구성: 세 장면
  1. 연인 — 붉은 장미 소형 꽃다발
  2. 부모·스승 — 분홍과 크림 장미 혼합 꽃바구니
  3. 친구·축하 — 노랑과 주황 장미 밝은 꽃다발
- 설명: 꽃송이 수의 의미를 보편적 규칙처럼 제시하지 않음
- 금지: 특정 브랜드 로고, 과도한 명품 포장, 인물 얼굴 중심 연출

---

## 이미지 6｜장미 오래 보는 관리 카드

- 비율: 16:9
- 삽입 위치: 관리법 섹션
- 역할: 절화 관리의 핵심을 한눈에 정리
- 구성:
  1. 깨끗한 화병
  2. 물에 잠길 잎 제거
  3. 줄기 끝 다시 자르기
  4. 절화 영양제 사용
  5. 2~4일마다 물 교체와 재절단
  6. 난방기·직사광선을 피한 서늘한 곳
- 시각 스타일: 실제 손과 도구를 사용한 단계별 생활 인포그래픽
