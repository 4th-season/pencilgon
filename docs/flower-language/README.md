## 1. 시리즈 정체성

「꽃과 꽃말」은 꽃말 한 줄을 나열하는 사전이 아니다. 각 글은 **한 종류의 꽃을 주인공**으로 삼고, 다음 네 요소를 함께 다룬다.

1. 꽃의 생김새와 식물학적 특징
2. 꽃말이 만들어진 역사·신화·문화적 배경
3. 한국에서 받아들여진 상징과 생활문화
4. 선물·꽃다발·원예·축제와 연결되는 실용 정보

상업성은 광고 문장을 늘리는 방식이 아니라, 독자가 실제로 궁금해하는 **색깔별 의미, 선물 상황, 개화 시기, 꽃다발 형태, 관리법, 비슷한 꽃 구분**을 정확하게 제공하는 방식으로 확보한다.

## 2. 제목 작성 원칙

### 고정 형식

`[꽃과 꽃말] ㆍ주제ㆍ부주제`

### 예시

- `[꽃과 꽃말] ㆍ장미ㆍ색깔마다 달라지는 사랑의 언어`
- `[꽃과 꽃말] ㆍ수국ㆍ변하는 빛깔에 담긴 마음의 변화`
- `[꽃과 꽃말] ㆍ동백ㆍ추위 속에서도 떨어지지 않는 붉은 마음`

### 제목 기준

- **주제**에는 꽃 이름만 넣는다.
- **부주제**에는 꽃의 대표 상징과 검색자가 얻을 핵심 정보를 함께 넣는다.
- ‘진짜 꽃말’, ‘절대 선물하면 안 되는 꽃’처럼 근거 없이 단정하거나 과장하지 않는다.
- 색상·문화권·시대에 따라 의미가 다르면 제목과 본문에서 그 차이를 드러낸다.

## 3. 매회 작성 전 확인할 원칙

각 글을 시작하기 전에 다음 항목을 반드시 다시 확인한다.

- [ ] 이번 글의 대상이 **한 종류의 꽃**으로 분명한가
- [ ] 표준 이름·학명·과명은 공신력 있는 식물 자료로 확인했는가
- [ ] 꽃말을 하나의 고정된 정답처럼 단정하지 않았는가
- [ ] 서양 꽃말과 한국의 문화적 상징을 구분했는가
- [ ] 신화·전설·역사 일화의 출처를 확인했는가
- [ ] 독자가 꽃을 실제로 식별할 수 있는 이미지를 우선 배치했는가
- [ ] 색깔별 꽃말은 상업 꽃말과 역사적 상징을 구분했는가
- [ ] 선물 추천은 관계·상황·색상에 따른 오해 가능성까지 설명했는가
- [ ] 개화 시기·축제 일정은 발행 시점의 공식 정보를 확인했는가
- [ ] 임시 주소, `href="#"`, 확인되지 않은 축제 링크를 넣지 않았는가
- [ ] 표·카드·인포그래픽 뒤에 쉬운 부연 설명을 3~4줄 붙였는가
- [ ] 꽃의 실물 설명보다 감성 문장이 지나치게 많지 않은가

## 4. 본문 고정 구조

본문 HTML에는 별도의 H1을 넣지 않고, 티스토리 제목 영역에 고정 제목 형식을 사용한다.

### 표지 영역

- 녹색 또는 해당 꽃과 어울리는 짙은 자연색 배경
- 노란색·크림색 계열 메타 정보 박스
- 꽃 이름을 크게 보여주는 보조 제목
- 대표 꽃 이미지
- 120~160자 내외 안내글

### H2 구성

1. **장면으로 만나는 꽃**  
   꽃을 처음 보았을 때 인식할 수 있는 생김새와 계절 장면

2. **이 꽃을 한눈에 보면**  
   표준명·학명·과명·형태·개화 시기·대표 색상

3. **가장 널리 알려진 꽃말**  
   대표 의미와 그 의미가 생긴 배경

4. **색깔과 품종에 따라 달라지는 뜻**  
   색상별·품종별 의미 차이와 상업적 관습

5. **신화·역사·문화에서 피어난 상징**  
   신화, 종교, 문학, 회화, 국가·도시 상징

6. **한국에서 이 꽃을 바라본 방식**  
   민속, 문양, 시와 노래, 생활문화, 지역 축제

7. **선물할 때는 이렇게 읽습니다**  
   관계별 적합도, 꽃다발·꽃바구니·화분 선택, 주의할 색상

8. **오래 보고 싶다면**  
   절화·화분 관리, 독성·향·꽃가루 등 안전 정보

9. **비슷한 꽃과 구분하기**  
   혼동하기 쉬운 꽃을 이미지와 비교 카드로 설명

10. **꽃이 남기는 한 문장**  
   의미를 단정하지 않는 성숙한 마무리

꽃에 따라 불필요한 H2는 합치되, **식물 설명 → 꽃말 → 상징 → 실용 정보**의 흐름은 유지한다.

## 5. 이미지 작성 원칙

꽃 시리즈에서는 텍스트보다 먼저 **대상을 정확히 보여주는 이미지**가 필요하다.

### 글 1편당 기본 이미지 세트

| 번호 | 역할 | 권장 비율 | 내용 |
|---|---|---:|---|
| 0 | 썸네일 | 1:1 | 꽃 이름과 대표 상징을 한눈에 보여주는 표지 |
| 1 | 대표 대상 이미지 | 16:9 | 꽃 형태가 분명한 실사형 단독 또는 군락 사진 |
| 2 | 식별용 상세 이미지 | 1:1 | 꽃잎·꽃술·잎·가시·줄기 등 핵심 특징 |
| 3 | 색상·품종 비교 | 16:9 | 대표 색상 또는 품종을 나란히 비교 |
| 4 | 꽃말·상징 인포그래픽 | 16:9 | 핵심 의미와 문화적 배경을 시각화 |
| 5 | 선물·생활 장면 | 16:9 | 꽃다발·부케·화분 등 실제 사용 장면 |
| 6 | 비교·관리 카드 | 16:9 | 비슷한 꽃 구분 또는 절화 관리법 |

### 이미지 제작 구분

- **대상 식별용 이미지:** 실제 꽃의 형태가 우선이다. 생성형 이미지 사용 시 꽃잎 수, 잎 배열, 꽃술, 가시 등 왜곡 여부를 반드시 점검한다.
- **상징 설명 이미지:** 신화·문학·감정·선물 장면은 생성형 이미지 또는 설명형 인포그래픽을 사용할 수 있다.
- **비교 이미지:** 색상·품종·유사 꽃의 차이가 한눈에 보이도록 같은 구도와 크기를 사용한다.
- **텍스트 삽입:** 이미지 안의 글은 최소화하고, 제목 1줄과 핵심어 3~5개만 사용한다.
- **저작권:** 외부 실사 사진을 사용할 때는 공식 기관·직접 촬영·사용 허가·라이선스를 확인한다. 단순 검색 결과 이미지를 다운로드해 재사용하지 않는다.

### 이미지와 본문 연결

모든 이미지는 해당 H2의 설명에 직접 대응해야 한다. 예쁜 꽃 사진을 반복해서 넣지 않고, 이미지 뒤에는 다음을 3~4문장으로 설명한다.

1. 이미지에서 무엇을 보아야 하는가
2. 꽃의 실제 특징과 어떤 관련이 있는가
3. 꽃말·상징과 어떻게 연결되는가
4. 흔히 오해하는 부분은 무엇인가

## 7. 상업성 적용 원칙

상업적 정보는 꽃의 의미를 충분히 설명한 뒤 배치한다.

`꽃의 특징 → 꽃말의 배경 → 색상 차이 → 선물 상황 → 상품 형태 → 관리법`

### 자연스럽게 연결할 수 있는 영역

- 꽃다발·꽃바구니·부케
- 개업·승진용 화분과 난
- 절화 영양제·꽃병·꽃가위
- 구근·모종·원예용품
- 프리저브드·드라이플라워
- 지역 꽃축제·여행·숙박

특정 상품을 먼저 추천하지 않고, 독자가 **어떤 기준으로 선택해야 하는지**를 먼저 제공한다.
