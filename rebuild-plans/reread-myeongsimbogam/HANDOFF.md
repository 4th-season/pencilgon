- 저장소: `4th-season/pencilgon`
- 브랜치: `main`

## 기준 데이터

- `data/passages.json`: 6편 42구절 누적 원문 데이터
- `data/sections.json`: 명심보감 20편 작업 목록
- `data/sources.json`: 사용 출전과 확인 주소
- `data/chapter-source-map.json`: 장별 출전 매핑
- `data/structure-note.json`: 구조 관련 주의 사항

## 현재 진행 현황

- 누적 입력 구절: 42
- 입력 완료 편: 6 / 20
- 계선편: 10구절
- 천명편: 7구절
- 순명편: 5구절
- 효행편: 6구절
- 안분편: 6구절
- 근학편: 8구절

대기 편: 정기편, 존심편, 계성편, 훈자편, 성심편 상·하, 입교편, 치정편, 치가편, 안의편, 준례편, 언어편, 교우편, 부행편

## 최근 HTML 작성 진행

티스토리용 완성 HTML은 계선편·천명편·순명편·효행편을 거쳐 정기편 23장까지 작성했다. 다음 HTML 작업은 정기편 24장부터 시작한다. 다만 이 저장 경로의 원문 기준 데이터는 4차 누적본 42구절 스냅샷이므로, 정기편 데이터는 공식 DB와 재검증한 뒤 `passages.json`에 추가한다.

## 다음 원칙

1. 흐름으로 원문과 번호를 추정하지 않는다.
2. 공식 DB의 편명·장 번호·원문 글자를 먼저 확인한다.
3. 통행본과 출전 원문의 글자 차이를 기록한다.
4. 원문 데이터와 HTML 해설 원고를 분리해 관리한다.
5. 수정 시 검증 기록과 진행 현황도 함께 갱신한다.
