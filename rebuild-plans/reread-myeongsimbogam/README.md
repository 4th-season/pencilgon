# Re:Read 명심보감 원문 정리

이 디렉터리는 「Re:Read 명심보감」 연재를 위한 원문 기준 데이터와 검증 기록을 보관한다.

## 저장 기준

- 원문 배열과 글자는 전통문화연구회 동양고전종합DB를 최우선 기준으로 확인한다.
- `data/passages.json`을 원문·독음·풀이·출전의 기준 데이터로 사용한다.
- `data/chapter-source-map.json`은 편·장별 출전 대응표다.
- `review/`에는 H1 목록, 진행 현황, 검증 결과와 출전 확인 기록을 둔다.
- HTML 연재 글은 이 기준 데이터를 바탕으로 별도 작성한다.

## 현재 스냅샷

- 기준 파일: 명심보감 원문정리 6편 42구절 4차 누적본
- 원문 데이터 입력: 42구절
- 입력 완료 편: 계선편, 천명편, 순명편, 효행편, 안분편, 근학편
- 후속 작업에서는 정기편 원문 데이터를 공식 DB와 재대조하여 추가한다.
