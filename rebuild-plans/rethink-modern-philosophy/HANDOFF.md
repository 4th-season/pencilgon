## 4. Re:Think 글의 정체성

Re:Think는 개념 정의를 모아 놓은 정답형 철학사전이 아니다.

철학 개념은 현실을 한 번에 설명하는 결론이 아니라, 익숙한 판단을 다시 묻게 하는 렌즈다. 글은 독자에게 “이 개념의 뜻은 이것이다”만 전달해서는 안 된다. 그 개념을 통해 지금의 삶과 사회가 무엇을 자연스럽게 전제하고 있었는지 드러내야 한다.

### 기본 사유 흐름

1. **삶의 장면**  
   독자가 실제로 겪거나 목격할 법한 구체 장면을 제시한다.

2. **불편한 의문**  
   장면을 간단한 도덕 판단으로 닫지 않고 무엇이 이상한지 묻는다.

3. **철학 개념으로 읽기**  
   개념의 의미·계보·핵심 구분을 현실 장면과 연결한다.

4. **설명 가능한 지점**  
   이 개념이 무엇을 새롭게 보게 하는지 밝힌다.

5. **설명이 부족한 지점**  
   개념이 놓치는 몸·역사·권력·타자의 경험·구체적 조건을 검토한다.

6. **다시 질문으로 남기기**  
   실천 팁이나 정답이 아니라 독자가 자신의 판단 기준을 되묻게 한다.

## 5. 글 완성도 유지 기준

### 5-1. 도입

- 개념 정의부터 시작하지 않는다.
- 사건의 요약보다 한 사람이 실제로 어떤 말을 듣고 어떻게 판단하게 되었는지를 보여 준다.
- 도입 장면은 본문 전체의 철학적 질문으로 이어져야 한다.
- 이미 결론이 정해진 교훈용 사례를 만들지 않는다.

### 5-2. 개념 설명

- 사전적 정의는 짧고 정확하게 제시한다.
- 인접 개념과의 차이를 명확히 한다.
- 철학자 이름은 최소한으로 사용하되 실제 개념적 기여가 드러나게 한다.
- 철학자의 복잡한 논의를 한 문장으로 과장하거나 현대 문제의 직접 해답처럼 사용하지 않는다.
- 개념의 강점과 한계를 함께 다룬다.

### 5-3. 현실 연결

- 개인 심리만으로 설명하지 않는다.
- 관계·조직·제도·언론·플랫폼·AI·권력 구조가 관련될 때 함께 본다.
- 개인 책임을 지우지도 않고 구조만으로 개인 선택을 없애지도 않는다.
- 피해와 책임이 있는 문제를 단순한 오해나 관점 차이로 축소하지 않는다.

### 5-4. 시각 구성

- 긴 서술이 4~6문단 이어지기 전에 의미 있는 시각요소를 배치한다.
- 카드 수를 무조건 늘리지 않는다.
- 한 화면에 지나치게 작은 카드가 많이 생기지 않도록 PC 4~5열, 모바일 1~2열로 조정한다.
- 반복되는 원형 지도만 사용하지 말고 글의 핵심 구조에 맞게 흐름도·겹침 구조·축·계단·대비 구조를 바꾼다.
- 시각도구는 내용을 대신하지 않는다.
- 시각도구 뒤에는 독자의 생활 장면과 연결하는 쉬운 설명을 붙인다.

### 5-5. 문장

- 개념어는 필요한 곳에서 굵게 처리한다.
- 짧은 문장만 반복해 본문이 지나치게 잘게 끊어지지 않게 한다.
- 반대로 한 문단에 여러 논점을 몰아넣지 않는다.
- “결국”, “본질적으로”, “현대사회는” 같은 단정은 근거 없이 남용하지 않는다.
- 독자를 가르치거나 훈계하는 어조보다 함께 질문하는 어조를 유지한다.

### 5-6. 결말

- “따라서 우리는 ○○해야 한다”로 닫지 않는다.
- 실천 체크리스트를 결론으로 두지 않는다.
- 개념이 제공한 설명과 남긴 한계를 함께 회수한다.
- 독자의 삶·관계·사회적 기준으로 돌아오는 한두 개의 질문을 남긴다.

## 6. 티스토리 HTML 형식

1. 최상단에 스타일 없는 `<h1>`을 둔다.
2. `<style>`은 H1 아래에 둔다.
3. 전체 래퍼는 개념마다 고유한 class 접두어를 사용한다.
4. 메타 박스는 녹색 계열, 노란색 강조선 또는 라벨을 사용한다.
5. 표지는 H1을 쉬운 말로 변형한 큰 제목과 짧은 도입 설명을 포함한다.
6. 반응형 CSS를 포함한다.
7. 외부 라이브러리와 JavaScript에 의존하지 않는다.
8. 티스토리 HTML 모드에 바로 붙여 넣을 수 있는 완성본이어야 한다.
9. 출력은 반드시 일반 코드블록으로 한다.

올바른 출력:

~~~text
```html
<h1>...</h1>
...
```
~~~

금지 출력:

~~~text
```html id="abc123"
...
```
~~~

### 권장 삶의 장면

조직에서 구조조정을 “군살 빼기”, 경쟁을 “전쟁”, 청년을 “미래의 자원”, 돌봄을 “부담”이라고 부르는 장면을 사용할 수 있다. 단순한 표현의 아름다움이 아니라, 은유가 어떤 행동과 정책을 자연스럽게 만드는지를 묻는다.

### 핵심 렌즈

- 은유는 꾸밈말만이 아니라 한 영역을 다른 영역으로 이해하게 하는 인식 틀이다.
- “시간은 돈이다”, “논쟁은 전쟁이다” 같은 개념적 은유
- 은유는 복잡한 현실을 이해하게 하지만 특정 측면만 강조한다.
- 같은 대상을 “비용”, “권리”, “투자”, “부담”으로 부를 때 판단이 달라진다.
- 은유는 현실을 묘사하면서 동시에 가능한 행동의 범위를 만든다.
- 모든 은유가 조작은 아니지만, 반복되는 은유에는 권력과 이해관계가 개입할 수 있다.
- 은유를 바꾸는 것이 현실을 자동으로 바꾸지는 않는다.
- 몸·경험·문화에 따라 같은 은유의 효과가 다를 수 있다.

### 철학·이론 후보

- 아리스토텔레스: 낯선 것 사이의 유사성을 보는 능력
- 니체: 개념과 진리의 은유적 성격
- 리쾨르: 살아 있는 은유가 새로운 의미를 여는 과정
- 레이코프와 존슨: 개념적 은유, 일상적 사고를 조직하는 은유

철학자 네 명을 모두 반드시 넣지 않는다. 글의 장면과 논리를 살리는 범위만 사용한다.

### 피해야 할 결론

- 좋은 은유를 쓰면 사회문제가 해결된다는 결론
- 모든 언어는 은유이므로 사실은 없다는 단정
- 은유는 항상 선전이나 조작이라는 단정
- 표현을 바꾸는 것만으로 구조적 현실이 바뀐다는 주장

### 마지막 질문 후보

- 나는 현실을 설명하기 위해 은유를 사용하고 있는가, 아니면 익숙한 은유가 무엇을 현실로 볼지 대신 정하고 있는가?
- 어떤 은유가 나의 삶을 이해하게 했고, 어떤 삶의 가능성을 보이지 않게 만들었는가?
